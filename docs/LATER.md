# Later

Good ideas that are not in the MVP.

Parking something here is a decision, not a loss. It is how the MVP
stays small enough to actually ship by Session 3.

- **Admin role and account management** — creating, editing and
  deleting accounts for all users.
- **ITSD-issued ID creation** — generating student ID numbers.
- **Typing scores into the app** — for now, scores stay in Google Sheets
  and are uploaded as a CSV.
- **Reading Google Sheets directly** — connecting to Google instead of
  uploading a CSV.
- **Other teachers** — the MVP has one teacher, Justine.
- **Notifications** — telling students when new scores are uploaded.
- **Calculating final grades** — the app shows the breakdown only.
- **Project name** — decide later.
- **Saving each week's upload as a separate version** — students see
  the latest upload, which already holds every item so far.
- **Locking out repeated wrong access codes** — slows down anyone
  guessing codes.
- **Students resetting their own access code** — for now, Justine
  issues a new one.
- **Emailing or texting access codes** — for now, Justine prints them.
