# 06 — Weekly re-upload and New code

**What to build:** Justine uploads this week's CSV for a section that
already has students. Scores update, existing access codes stay the
same, and Justine can give any student a new code.

**Blocked by:** 04

**Status:** todo

- [ ] A New code button on each student row replaces their code
